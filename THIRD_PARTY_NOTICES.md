# Source attribution

This collection was generated by primorLee with gravity variants, paired seeds,
gravity-aware prompts, first-frame exports and physics-state exports. It is not
the official PhyCo-Sim dataset and does not claim authorship of its simulation pipeline.

## PhyCo-Sim

- Source: https://github.com/nnsriram97/phyco-sim
- Fixed generation version: `bd8a3b4eb54fa1ad008250e2033a1f8369bff6d3`
- License at that version: [CC BY-NC 4.0](https://github.com/nnsriram97/phyco-sim/blob/bd8a3b4eb54fa1ad008250e2033a1f8369bff6d3/LICENSE)
- Paper: Sriram Narayanan, Ziyu Jiang, Srinivasa G. Narasimhan and Manmohan Chandraker,
  *PhyCo: Learning Controllable Physical Priors for Generative Motion*, CVPR 2026.
- Project: https://phyco-video.github.io/

The dataset follows the upstream scene and parameter sampling with the collection-specific
changes listed above. The original simulation source and its history are not distributed here.

## Kubric

PhyCo-Sim vendors and modifies [Kubric](https://github.com/google-research/kubric),
Google Research's simulation framework, under Apache License 2.0. That license continues
to apply to the vendored Kubric code in PhyCo-Sim. This repository contains generated
outputs rather than a redistribution of the Kubric source tree.

## Poly Haven

Textures and HDRI lighting derive from a cached subset of [Poly Haven](https://polyhaven.com/)
assets. Poly Haven assets are offered under [CC0](https://polyhaven.com/license).
The original complete asset library and a per-asset inventory are not included in this release.
The dataset's CC BY-NC 4.0 license does not change the licenses of those original assets.
